## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/risen-laboratories-react.git
```

Go to project folder

```bash
cd risen-laboratories-react
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build project

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
